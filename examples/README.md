# Ontology example

`ontology_payload.json` contains the first object/action pair from a default seed-42 run.
It is generated from actual pipeline output; it is not a Foundry API request body.

To inspect the complete envelope, run `python -m src.pipeline` and open
`artifacts/ontology_payload.json`. Field mapping and action submission requirements are
documented in [the Foundry integration guide](../docs/FOUNDRY.md).
